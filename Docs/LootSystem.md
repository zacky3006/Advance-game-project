# ระบบขโมยของด้วยปุ่ม F

## ทดลองใน Unreal Editor

1. ปิด Editor แล้ว Build `ArenaGameEditor` จาก Rider จากนั้นเปิดโปรเจกต์ใหม่ (มีคลาสและ UPROPERTY ใหม่ จึงควร Build เต็มแทน Live Coding)
2. ใน Content Browser เปิด C++ Classes → ArenaGame แล้วสร้าง Blueprint จาก `LootPickup` ชื่อ `BP_LootPickup`
3. ลาก Blueprint ลงในบ้าน ตำแหน่งที่ผู้เล่นเดินถึงได้ ตัวเริ่มต้นเป็นกล่องขนาด 30 ซม. ไม่ต้องโหลด Fab ก่อน
4. ตั้ง `Item Name` เช่น `Gold Watch` และ `Value` เช่น `1500` ใน Details ของแต่ละชิ้น
5. กด Play เดินเข้าใกล้ไม่เกิน 200 ซม. จะมีการ์ด `[F] Steal` พร้อมชื่อและมูลค่าอยู่เหนือไอเทมที่เลือก ข้อความติดตามตำแหน่งไอเทมบนจอเมื่อหมุนกล้อง กด F ของจะหายไป และยอดจำนวน/มูลค่ามุมขวาบนจะเพิ่ม
6. วางสองชิ้นใกล้กัน ระบบเลือกทีละชิ้นโดยให้น้ำหนักกับชิ้นใกล้กลางจอ แล้วพิจารณาระยะจากตัวละครด้วย ชิ้นที่เลือกมีเส้นขอบสีเหลืองและป้าย `[F] Steal` กด F จะเก็บชิ้นเดียวกับที่ไฮไลต์ เก็บแล้วจึงเลือกชิ้นถัดไป

ใช้กับตัวละครที่สืบทอดจาก `ArenaGameCharacter` ซึ่งมี `LootCollector` และผูกปุ่ม F ให้แล้ว ไม่ต้องสร้าง Input Action เพิ่ม หาก Blueprint เดิมใช้ F อยู่ ควรย้ายปุ่มเดิมหรือยกเลิก binding นั้น

## เปลี่ยนเป็นโมเดล Fab

เปิด `BP_LootPickup` เลือก component `Mesh` แล้วเปลี่ยน Static Mesh ปรับ Scale ให้เหมาะกับขนาดโมเดล (กล่องเริ่มต้นใช้ 0.3) และปรับชื่อ/มูลค่า โมเดลต้องมี collision สำหรับ query และบล็อก Visibility; ใช้ collision preset `BlockAllDynamic` ตามค่าเริ่มต้น หากไม่มี collision ให้สร้าง simple collision ใน Static Mesh Editor

## ข้อมูลและ Blueprint

HUD มุมขวาบนเป็นการ์ดสีเข้มขอบมนธีมเดียวกับหน้ากระเป๋า มีหัวข้อทอง `YOUR HAUL` แสดง `Loot: 0 items` และ `Total: $0` แยกบรรทัด พร้อม `[TAB] View haul` เมื่อเซิร์ฟเวอร์ยืนยันว่าเก็บสำเร็จ ตัวเลขและพื้นหลังจะกระพริบเขียว การ์ดขยายเล็กน้อย และแสดงยอดเพิ่ม เช่น `+1 items +$100` ก่อนลอยและจางหายใน 1.8 วินาที หากเก็บติดกันจะรวมยอดเพิ่มและเริ่มเอฟเฟกต์ใหม่ รองรับเจ้าของตัวละครทั้ง standalone และ multiplayer

- `LootCollector.Inventory`: รายการชื่อและมูลค่าที่เก็บแล้ว
- `LootCollector.GetTotalValue`: มูลค่ารวม
- `LootCollector.OnInventoryChanged`: event สำหรับต่อ UI เพิ่มเติม
- `LootCollector.PickupRange`: ระยะเก็บ หน่วยเซนติเมตร
- `LootCollector.FocusHalfAngle`: มุมเลือกของจากแนวกล้อง ค่าเริ่มต้น 65 องศา ของนอกระยะ ของด้านหลัง และของที่มีผนังบังจะไม่ถูกเลือก มีระยะผ่อนเล็กน้อยในการเปลี่ยนเป้าหมายเพื่อป้องกันกรอบสั่นสลับสองชิ้น
- `LootCollector.TryInteract`: เรียกจากปุ่ม UI หรือระบบ input อื่นได้
- `LootCollector.ToggleInventory`: เปิด/ปิดหน้าสรุปของในกระเป๋า (ผูก Tab ให้แล้ว)

เซิร์ฟเวอร์ตรวจระยะ สุขภาพ และผนังกั้นก่อนเพิ่มรายการ ของแต่ละชิ้นเก็บได้ครั้งเดียวและหายจากทุกเครื่อง Inventory ส่งกลับเฉพาะเจ้าของตัวละคร ทดสอบ multiplayer ด้วย Play จำนวนผู้เล่น 2 คน แล้วลองเก็บชิ้นเดียวกัน ยอดต้องเพิ่มเฉพาะคนที่เก็บสำเร็จ

ข้อมูลตอนนี้อยู่กับตัวละครในรอบเล่น เมื่อสร้างตัวละครใหม่หรือออกเกมจะไม่เก็บต่อ ยังไม่มี SaveGame, ระบบขายของ หรือจำกัดกระเป๋า HUD เริ่มต้นใช้ภาษาอังกฤษเพื่อแสดงได้ด้วยฟอนต์เริ่มต้น

## เส้นขอบไอเทม

วัสดุ `Content/UI/Materials/M_LootOutline` วาดเปลือกด้านหลังขยายออกจาก mesh สีเหลือง โดยไม่เปลี่ยนวัสดุเดิมของไอเทม ไม่ต้องตั้ง Post Process Volume หรือ Custom Depth เพิ่ม ความหนาปรับได้ที่ scalar parameter `OutlineWidth` ใน material (เริ่มต้น 1.25 ซม.) เหมาะกับ Static Mesh แบบปิดผิว วัตถุเป็นแผ่นบางหรือโปร่งใสอาจต้องปรับวัสดุเส้นขอบให้เหมาะกับโมเดล

สร้าง mesh เส้นขอบเพียงหนึ่งชุดต่อผู้เล่นและแสดงเฉพาะเจ้าของ จึงไม่เปลี่ยนเป้าหมายไฮไลต์ของผู้เล่นคนอื่น ออกจากระยะหรือเก็บของแล้วกรอบจะหายไป

สคริปต์ `Scripts/CreateLootOutline.py` ใช้สร้าง material ต้นฉบับครั้งแรก ไฟล์ material ถูกสร้างไว้แล้วและอ้างอิงจาก C++ ไม่ต้องรันสคริปต์เพื่อเล่นเกม

ทดสอบ: วางไอเทมสองชิ้นใกล้กัน เลื่อนกล้องสลับมองแต่ละชิ้น ตรวจว่ามีกรอบและป้ายเพียงชิ้นเดียว กด F แล้วตรวจว่าชิ้นที่มีกรอบหายและยอดเพิ่มเพียงครั้งเดียว จากนั้นลองเดินออกระยะ ยืนหลังผนัง และสลับ First/Third Person ด้วย C

## หน้ากระเป๋า Tab

กด Tab เพื่อเปิดหน้าสรุป `YOUR HAUL` กด Tab, Esc หรือปุ่ม Close เพื่อกลับเกม หน้าต่างโทนเข้มตัดทอง มีแอนิเมชันเปิด เมาส์สำหรับเลื่อนรายการ และปุ่มสลับการเรียงตามมูลค่ารวมของแต่ละแถวหรือชื่อ

แต่ละแถวแสดงรูปเล็ก ชื่อ ราคาต่อชิ้น จำนวน และมูลค่ารวมของแถว ของที่ชื่อ ราคา โมเดล และวัสดุตรงกันจะรวมเป็นแถวเดียว ด้านบนแสดงจำนวนของทั้งหมด (นับทุกชิ้น) และมูลค่ารวม หากยังไม่ได้เก็บอะไรจะแสดงข้อความกระเป๋าว่าง

รูปในกระเป๋าสร้างจาก Static Mesh และวัสดุของไอเทมที่เก็บโดยตรง ระบบถ่ายภาพพรีวิวโมเดลครั้งเดียวและแคชไว้ในเครื่อง ไม่ต้องเตรียมรูปหรือกำหนด `Item Icon` เมื่อเปลี่ยนโมเดลของชิ้นที่วางในฉากและเก็บใหม่ รูปจะเป็นโมเดลนั้นด้วย ข้อมูลโมเดลและวัสดุถูกบันทึกก่อนทำลายไอเทม จึงยังแสดงได้หลังเก็บแล้ว `Item Icon` ใช้สำรองเฉพาะรายการที่ไม่มีโมเดลเท่านั้น

ภาพพรีวิวใช้โลกสตูดิโอแยกจากโลกเกม มีแสงหลัก/แสงเติมสีขาว exposure คงที่ และพื้นหลังสีเทากลาง ปิด fog/atmosphere/cloud เพื่อไม่ให้สีฟ้าจากฉากคลุมไอเทม ใช้ภาพ 256×256 ย่อแสดงในช่อง 64×64 และมีพื้นหลังหลังโมเดลเพื่อให้มองเห็นวัสดุแก้วได้ชัดขึ้น หลังอัปเดตระบบให้เริ่ม Play รอบใหม่เพื่อสร้างแคชภาพใหม่

ทดสอบภาพด้วย Automation Test `ArenaGame.Loot.ThumbnailPreview` รูปที่เรนเดอร์จริงจะบันทึกไว้ที่ `Saved/Automation/LootThumbnails` ครอบคลุมกล่องมาตรฐาน ถังขยะ และแก้ว พร้อมตรวจว่ามีความต่างของความสว่างให้เห็นรูปทรง

สีทอง สีพื้นเข้ม สีข้อความรอง สีเขียว และรูปแบบขอบการ์ดใช้จาก `LootUITheme.h` ร่วมกันทั้งหน้ากระเป๋า HUD และป้ายเก็บของ ป้ายเหนือไอเทมมีปุ่ม F สีทอง ชื่อสีขาว และราคาสีเขียว พร้อมแอนิเมชันปรากฏเมื่อเปลี่ยนเป้าหมาย

ขณะเปิดหน้ากระเป๋าจะหยุดรับคำสั่งเดิน หมุนกล้อง เก็บของ และสลับกล้อง เพื่อใช้เมาส์กับ UI เมื่อปิดจะคืนการควบคุม เกมยังดำเนินต่อ (ไม่ได้ pause โลกเกม) และ C ยังคงเป็นปุ่มสลับกล้อง

ทดสอบ: เปิด Tab ตอนกระเป๋าว่าง ปิดด้วย Tab/Esc/Close เก็บของชนิดเดียวกันสองชิ้นและของอีกชนิดหนึ่ง ตรวจจำนวน มูลค่าต่อแถว และยอดรวม ลองเลื่อนรายการ สลับเรียง และตรวจว่ากลับมาเดิน หมุนกล้อง เก็บของ และใช้ C ได้ตามปกติ
